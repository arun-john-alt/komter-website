# KOMTER website

Static website for Komter Equipments Pvt Ltd (air compressors, Chennai), in three versions for the client to choose
from: `clean/`, `market/` and `impeccable/`. Each has a home page and a range page. Plain HTML, CSS and a little
JavaScript; no build step. Published with GitHub Pages.

Every page carries `noindex, nofollow` until a version is chosen and goes live on the client's domain.
